## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎥 **Cinematic Hero Section** | Full-screen animated hero with interactive media particle canvas, fluid typography, and a live event countdown timer |
| 👥 **Team Members Directory** | Full organizational hierarchy — from Media Head to Core Members — with individual profile cards, bios, and social links |
| 🏢 **Creative Departments** | Showcase of specialized wings — Photography, Videography, Reels, Podcasts, Content Design, and Mobile Photography |
| 🎨 **Media Gallery & Works** | Dedicated pages for the team's best photography, videos, and creative works |
| 👨‍👩‍👧‍👦 **Media Team Family** | Heart of the team — showcasing the bond and culture behind the cameras |
| 🚀 **Why Join Us** | Compelling reasons to join the RGU Media Team with animated cards |
| 📋 **Recruitment Hub** | Live recruitment status with an integrated Google Forms application modal |
| ❓ **FAQ Section** | Accordion-style frequently asked questions for new applicants |
| 📬 **Contact Form** | Split-view contact section with form and university location details |
| 🔍 **Global Search** | `Ctrl+K` powered search modal to find anything across the site instantly |
| ⌨️ **Keyboard Shortcuts** | Power-user keyboard shortcuts for quick navigation |
| 🌙 **Dark Theme** | Premium dark UI with RGU's signature orange (#F26A2E) accent throughout |
| 📱 **Fully Responsive** | Pixel-perfect on mobile, tablet, and desktop |
| ⚡ **Performance Optimized** | Lighthouse-optimized with lazy loading, code splitting, and Vite bundling |
| 🎭 **Micro-Animations** | Smooth scroll-triggered animations via Framer Motion throughout every section |

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18+ and **npm** installed

### Installation

```bash
# Clone the repository
git clone https://github.com/chinmoyy12/rgu-media-team.git
cd rgu-media-team

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at **http://localhost:3000**

### Build for Production

```bash
npm run build
```

The optimized output will be in the `dist/` directory.
